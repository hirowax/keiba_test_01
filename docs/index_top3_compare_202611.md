## 読み方の注意
- 統計的な判定はしていない（計画どおり。差し戻しの条件は置かない）。同じレースの複数の馬は独立した結果ではないので、信頼区間は出していない。
- 3着内率は、全期間・前半・後半のどれでも「新しく候補」＞「両方で候補」＞「候補から外れる」の順だった。回収率の順は期間で入れ替わる（例: 単勝は前半では新しく候補が両方で候補とほぼ同じ、後半では高い）。回収率は少数の高配当で大きく動く。
- 3つの分け方は別の馬の集まりで、レースの条件（頭数・クラス・人気の分布）がそろっていない。「新しく候補」には「*」付きの値の馬（近5走のデータがそろわない馬）と、同じ順位で入った馬が混ざる。違いの理由は調べていない。
- 点数（pt）と🔥は比べていない。修正前のデータは前走成績が別の馬の値なので、点数を正しく出せない（タスク8〜10で、新しい定義で作り直す）。
- 指数の表そのものの正しさ（例: 馬番1〜3だけの6日は取得異常で外れている）は、表の検査で外せるものしか外していない。
