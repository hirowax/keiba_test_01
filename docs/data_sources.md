# 取得項目の一覧（どこから取り、正しいと確認できているか）

最終更新: 2026-11-05。**新しい値を取る・取り方を変えたら、この表の行を追加・更新すること。**
「確認済み」は、実ページの構造を見た、または正解データと照合して一致を確かめた、という意味。
「未確認」の項目は、思い込みで書かれている可能性がある（2026-10-30 の2件の事故はどちらも未確認の項目だった）。

## 判定の基本ルール
- 値はクラス名などで**どのセルかを明示して**取る。「何列目」「最初の数字」「隠し値」で取らない。
- 取れなかったら空にして理由を残す。代わりの値で埋めない。
- 取った値が正しいかは、件数ではなく**正解データとの照合**で確かめる。
