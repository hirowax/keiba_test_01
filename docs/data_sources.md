## 判定の基本ルール
- 値はクラス名などで**どのセルかを明示して**取る。「何列目」「最初の数字」「隠し値」で取らない。
- 取れなかったら空にして理由を残す。代わりの値で埋めない。
- 取った値が正しいかは、件数ではなく**正解データとの照合**で確かめる。
