# 血統辞典プランA パイロット集計（2026-09-11）

**背景**: `CLAUDE.md`「血統辞典検証」節のプランAに従い実行。血統キャッシュが
全体の約48%（3,759/7,875頭）しかない時点でのパイロット集計であり、
**判断材料としては使わない**（下記の限界を参照）。

- スクリプト: `analyze_pedigree_dictionary.py`
- 対象: 全103日分の `race_conditions.json` × `race_results.json`
- 条件一致レース: 1,352レース、延べ出走頭数18,880頭、うち血統未取得74%（該当レース内）

父系のみ一致(N=244)の単勝回収率が85.2%とやや高い以外、いずれの区分も100%を下回る。

## 限界（重要）

1. **血統カバレッジ48%のパイロット版**。未取得馬（父母父とも空欄）は判定不能として
   集計から除外しており、**どの馬から先にキャッシュが埋まったかに依存する選択バイアス**が
   ある可能性を排除できない（全頭スクレイプは1回で行うとブロック懸念があるため保留・
   `docs/anaba_research_log.md` 同様に複数日に分割する運用）
2. **複勝データが上位3着馬のみ記録**（`race_results.json` の `place_odds` は3着以内でのみ
   取得される仕様のため）。3着内でも1,316件は複勝オッズ自体が欠損しており、複勝回収率は
   取得できた分のみの近似値
3. サンプルは103日分の全期間で、`anaba_research_log.md` が警告する「クリーン窓/汚染窓」
   の区別をしていない
4. 事前登録された判定基準（採用/不採用のしきい値）はまだ設定していない。今回は
   「現状での傾向確認」のみが目的
