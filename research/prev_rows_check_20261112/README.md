## 1. 前走が障害戦の馬
- 前走データの記録（11/7・11/8 の2日分・485頭）で、前走が障害戦の馬は3頭（11/7 東京8R 2020100233、11/8 東京8R 2019101351・2022106999）。3頭とも、距離が「障」で始まり、着順・人気は数字、指数が空で、今の規則では「指数を読めない（''）」の取得失敗。3頭とも候補ではなく、レースの「前走指数レース内1位」が保留になった。
- 3頭の今の馬ページ: 障害戦の行は 10行すべてで、指数のセル（class `TimeIndexHeadCell01`）が空白だけ（「**」ではない）。同じページの平地の行は 78行すべて数字（最新の行より前の行も数字なので、ログインした状態で取れている）。指数M の列も、障害戦の行は空。
- ログインしていない状態の表示は「**」（プレミアム登録の案内へのリンク。2026-11-05 確認）で、空とは別の表示。
- 言えないこと: 障害戦の行の指数がいつも空だとは言えない（見たのは 3頭・10行）。
